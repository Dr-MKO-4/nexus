# NEXUS AI

Plateforme multi-agents IA pour le marketing digital.

## Structure du projet

- `backend/`  Service backend Python (agents IA, orchestration, LLM, API)
- `frontend/`  Application web TypeScript
- `infrastructure/`  Configuration Docker, monitoring et reverse proxy
- `scripts/`  Scripts opérationnels (setup, déploiement, backup)
- `docs/`  Documentation technique et fonctionnelle

Voir le README de chaque dossier principal pour le détail de son contenu et de ses responsabilités.
