# Scripts NEXUS AI

Scripts opérationnels du projet.

## Contenu

- `setup/`  Initialisation de l'environnement de développement
- `deploy/`  Déploiement vers staging/production
- `backup/`  Sauvegarde et restauration des données

## Responsabilités

Automatiser les tâches opérationnelles récurrentes du cycle de vie du projet (installation, déploiement, sauvegarde).
